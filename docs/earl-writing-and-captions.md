# EARL 的正文、图注与强调方式

日期：2026-10-16。对照来源：[EARL 页面](https://expa-rl.github.io/)、页面 HTML，以及桌面浏览器中的加粗元素和计算样式。本文补充 [整体内容取舍分析](earl-project-page-analysis.md)，记录本轮对 Dyad 文案的修改依据。

## 1. TL;DR 承担一句话的工作

EARL 的 TL;DR 是一句完整的话，概括提出什么以及希望带来什么价值。接下来的独立段落才解释现有接口的问题、问题的原因、提出的接口变化，最后引出三个重点。

Dyad 的开场因此采用同样的职责划分：一句话介绍架构与代理价值；下一段解释语言推理与动作文本共用生成接口的问题、动作编码器、动态动作空间，再引出两种训练方式与三个结果。TL;DR 不再串接一份实验结论清单。

## 2. 正文沿着问题和能力展开

EARL 的第一节先交代为什么任务需要根据反馈调整策略，再用 Countdown 解释这种困难，接着给出表现与行为证据。第二节从部分可观测的交互困难进入隐藏数字排序，解释为什么必须操作环境，最后给出结果。

模型规格、训练细节不是段落的起点。读者先知道这项结果为什么有意义，再从 caption 核查具体评估设置。

上一版 Dyad 的问题在于把编辑选择写进了正文，例如解释选了哪个型号、保留了哪些训练环境、是否包括负向结果。这些句子在说明图表如何被挑选，没有推进研究本身的论点。本轮改为“问题 → 架构怎样回应 → 观察到的能力变化 → 含义”；图表选择的范围记录在 caption 和内部方案中。

## 3. 图表是页面自己的证据，拥有自己的编号和说明

EARL 将论文正文 Table 2 中的 Countdown 部分组织成网页 Figure 1；规划短语的网页 Table 1 对应论文附录 Table 8。网页编号由自己的阅读顺序决定。这个映射说明，之前把“避免引用论文编号”理解成“网页也不该有图表编号”过于宽泛。[论文 v2](https://arxiv.org/pdf/2510.07581v2)

图注先交代展示什么，再说明必要设置。Countdown 图注说明评价指标和任务，再写模型规格、多任务训练与测试设置。模型名称在 caption 中被加粗，正文因此可以集中解释能力。

当前 Dyad 的编号为：

| 页面编号 | 名称与用途 | caption 保留的必要信息 |
|---|---|---|
| Figure 1 | Jev、常规 LLM、Dyad 的概念对比 | 同一架构中的语言推理和直接动作选择 |
| Table 1 | JevBench 的直接决策能力 | 公开子集、准确率、4B、CodeGym/GRPO |
| Table 2 | 冻结 LLM 的模块化适配 | 9B、DIVE/GRPO、冻结对象、分数与变化单位 |
| Figure 2 | 向未见环境迁移 | 原始 9B 与 CodeGym/GRPO、Dyad-GRPO 三组比较 |
| Figure 3 | 通用能力保留 | 模型、变化单位、三项能力到 benchmark 的映射 |
| Figure 4 | 推理与动作决策的架构机制 | 独立动作编码和语言生成两条路线 |

用户进一步要求精简 caption：seed 数和评估流程不放在页面图注中；图例已经说明的内容不再重复。必要的模型、单位和 benchmark 对应关系仍保留。

这些是页面内编号，不沿用论文原图表序号。正文用普通锚点引用，点击只定位到已经可见的证据，不展开或解锁内容。

## 4. 加粗有不同职责

实际核对 EARL 的 strong 元素后，可以区分：

- 正文强调核心能力，例如根据反馈调整决策。
- 正文强调少量关键结果，例如达到结果所需的训练步数。
- 首次引入的方法缩写用于识别概念。
- 图注强调图表编号以及模型名称等关键设置。

它没有把整句实验设置或整段结论都加粗。Dyad 因此每个主节只保留少量语义重点：冻结适配强调不更新 LLM，迁移强调无需继续训练，能力节强调三项能力均有提升这一观察；caption 中加粗编号、短标题与模型名；表格中加粗配对表现更好的成绩。

## 5. Caption 也需要可读的排版

浏览器核对得到 EARL 的正文为 19.2px，Countdown 图注为 16px。上一版 Dyad 的图注更小、颜色更淡且居中，较长的设置说明读起来像次要脚注。

初版将图注对齐到 EARL 的 16px。用户随后要求再小一点，当前 Dyad 图注调整为桌面 14px、手机 13.6px，保留左对齐、正常文字颜色和加粗的编号及简短名称。caption 应能独立说明图表，不要求读者依赖悬停或展开操作。

## 6. 展示范围与数据可见性

按用户本轮选择，跨环境节只展示 CodeGym 训练后的结果。正文直接描述该训练设置与能力变化，caption 精确限定模型和算法，避免写成所有训练来源、所有模型都获得同样结果。

冻结实验直接使用可见的原生 HTML 表格。Figure 2 同时标出原始 LLM、GRPO、Dyad-GRPO 的绝对分数；Figure 3 直接标出两种方法相对原始模型的变化。页面没有折叠实验区、隐藏数据表或依赖点击才能看到的结果。图像替代文本保留数值，供屏幕阅读器使用。

## 7. 验收要点

1. TL;DR 恰好一句话，后接独立解释段落。
2. 主节标题后直接进入段落，保持单层结构。
3. 实验型号放在 caption；正文不再出现 Qwen3.5-9B 或“代表性子集”的编辑描述。
4. Table 1–2、Figure 1–4 均有独立编号、名称和简洁 caption，锚点只做定位。
5. 跨环境节和对应图只包含 CodeGym；完整源数据继续保留在仓库中。
6. 图中选择展示的分数和变化直接可读；没有通过展开、悬停或隐藏表格补全结果的要求。
