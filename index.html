Dyad: Extending Large Language Models with Native Typed Decision-Making

Yundaichuan Zhan1, Weishi Wang2, Wenbiao Liu3, Daniel Dahlmeier2, Chengwei Qin4, Juncheng Li1*, Fredrik D. Johansson5, Zhongqi Yue6
1Zhejiang University 2SAP 3Central South University 4HKUST (Guangzhou) 5Chalmers University of Technology 6Microsoft Research *Corresponding author
Paper χ arXiv

TL;DR: We introduce Dyad, an architecture that extends pretrained LLMs with native typed decision-making for more capable agents across environments.

LLM agents typically express both reasoning and actions as text. Dyad adds an action encoder for direct decisions over dynamic action spaces, while retaining language reasoning and supporting both frozen-LLM adaptation and joint training.

1. Modular Adaptation with a Frozen LLM

Pretrained LLMs already contain knowledge and reasoning skills that are useful for acting in an environment. Connecting these capabilities to executable decisions need not require changing the LLM itself. Dyad provides a separate action encoder that learns how the model’s internal state relates to the available operations, allowing environment rewards to improve decision-making without updating any LLM parameters.

Training only this encoder improves agent performance on four unseen environments (Table 1). The LLM continues to supply the interaction-state representation, while the added component learns to ground it in actions. These results demonstrate a modular way to adapt existing agents: decision-making can improve beyond the training environment while the pretrained LLM and its language head remain fixed.

2. Cross-environment Generalization

Agents encounter environments with different operations, action descriptions, and interaction patterns. A decision interface that works only where it was trained would limit the benefits of post-training. Dyad constructs its decision head from the action descriptions supplied by each environment, allowing the same architecture to act over previously unseen choices.

To test transfer beyond the training environment, we jointly train the LLM and action encoder on CodeGym, then evaluate on four other environments without further training. The CodeGym-trained agent outperforms its conventional RL baseline across all four (Figure 1), spanning household interaction, web shopping, tool use, and software engineering. This shows that learning reasoning and typed decisions together can improve agent behavior beyond the environment providing the training rewards.

3. Preserving General Capabilities

Improving an agent’s ability to act should also preserve the skills that make a pretrained LLM useful across tasks. Learning language reasoning and environment control through the same generation interface may create interference between the two objectives. We therefore examine general knowledge, mathematical reasoning, and coding after agentic training, alongside performance in interactive environments.

Dyad recovers the knowledge and mathematics losses seen after DIVE training, while increasing the gains from CodeGym training (Figure 2). For the CodeGym-trained agent, all three capabilities improve over the original pretrained LLM. These results suggest that a separate route for adapting actions can help retain the language capabilities on which an agent’s reasoning depends.

Approach

Dyad separates the evolving interaction state from the meaning of an available action. The pretrained LLM encodes the interaction history, while an environment-conditioned action encoder maps each candidate description into a compatible representation. These action representations are computed independently and in parallel, enabling the decision head to accommodate changing action sets (Figure 3).

During reasoning, the language head generates vocabulary tokens as usual. When the model emits an interaction token, its current state is scored against the candidate action representations to produce a typed action distribution. The selected operation executes in the environment, and its observation returns to the history. Action representations can be reused while their descriptions and environment context stay unchanged; new actions are encoded when encountered.

Training begins with supervised alignment of the action projector, keeping both transformer backbones fixed. Reinforcement learning then learns from environment rewards. Frozen-LLM adaptation updates only the action encoder; joint optimization updates both the LLM and action encoder. The two training settings use the same decision architecture.
